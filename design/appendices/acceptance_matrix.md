# ことは 受入マトリクス

各機能を製品の能力・条件と対応付けて確認する。入力言語、訳先言語、文字体系、処理能力、資源条件を評価プロファイルへ記録する。機種名や固定の言語ペアを受入条件の基準とせず、選択した能力に適した試験を適用する。

## 機能別の確認

| ID | 機能 | 操作・条件 | 確認する証拠 |
|---|---|---|---|
| F01 | テキスト翻訳 | 複数の入力言語・訳先、原文変更、出力区間を扱う | 区間と訳先ごとの結果、取消と編集の整合 |
| F02 | 選択・共有取込み | 文字・資料の共有、権限失効、再開を扱う | 利用者が選んだ入力範囲、受渡しと再開 |
| F03 | 文章作成 | 原文・訳文を編集し文体・用語を変更する | 生成訳と編集訳の分離、影響範囲の再処理 |
| F04 | 訳文比較 | 複数モデル・設定・経路で同じ区間を処理する | 生成条件と原文の対応、比較の説明 |
| F05 | 用語と構造の管理 | 数値・固有表現・構造・用語の保持規則を適用する | 要確認箇所と保持検査、構造復元 |
| F06 | 画像翻訳 | 向き・文字体系・画質・複数領域を変えて認識する | 領域と文字の対応、OCR訂正の反映 |
| F07 | 撮影翻訳 | 撮影と範囲調整、認識、保存を順に操作する | 撮影資産と結果、権限変更への応答 |
| F08 | ライブ視覚翻訳 | 対象の移動・内容変化・負荷上昇を与える | 最新領域に適合する結果、更新頻度と待ち量 |
| F09 | 画面翻訳 | 許可された画面と範囲を取得する | 選択範囲、OSの許可、出典と表示 |
| F10 | PDF読解 | 文字PDF・画像PDF・多段組・縦横配置を処理する | 読順、ページ・領域・訳文の対応、修正 |
| F11 | Web・HTML読解 | 共有本文・保存HTML・許可された取得を扱う | 本文構造、出典、内容としての表示、通信方針 |
| F12 | 電子書籍読解 | 許可された書籍の章・目次・しおりを利用する | 読み位置、区間対照、取得権限と書出し条件 |
| F13 | Office資料翻訳 | 文書・スライド・表計算の指定要素を翻訳する | 数式・参照・構造の保持、文字あふれと再配置 |
| F14 | 構造化テキスト | 列・値・本文範囲を選んで処理する | キー・型・エスケープ・文書構造の保持 |
| F15 | 一括処理 | 複数資料の実行中に停止・容量変化・再開を行う | 資料別の成果と再開点、見積り・資源の整合 |
| F16 | 対照編集 | 区間を訂正・分割・結合し検索・置換する | 原文と編集の由来、対照、確定・要確認状態 |
| F17 | 音声入力 | 発話と区切りの手動・自動切替を行う | 原文確認、訳文、発話区間と操作の対応 |
| F18 | 録音翻訳 | 音声長・形式・話者・騒音を変えたファイルを処理する | 時刻対応、分割・再開、認識品質の条件 |
| F19 | 連続字幕 | 継続入力と負荷変化を与え、字幕を固定・再追従する | 遅延、待ち量、安定表示、保持予算 |
| F20 | 映像翻訳 | 音声・字幕トラック、時間軸、再生位置を変更する | 原資料と翻訳の同期、選択した処理経路 |
| F21 | 字幕編集・出力 | 字幕を分割・結合・時間調整して書き出す | 時間順序、表示条件、読み戻しの一致 |
| F22 | 再生音声取込み | 取得可能な再生経路の許可・選択・切断を扱う | OS能力、利用者の指定、取得状態 |
| F23 | フレーズ・学習 | 対訳を分類し復習・読み上げ・検索する | 承認済み内容、保存・出力の選択 |
| F24 | ライブラリ | 明示保存、選択した保持期限の満了、鍵の欠落・失敗、バックアップ・別端末復元、削除を行う | 暗号化・鍵とストアの対応・検索・資産参照と同意の照合、平文フォールバック・自動初期化なし、期限後の利用不可と未参照データの整理、復元の認証と読戻し、失敗時の既存データ保持、回復不能と削除範囲の説明 |
| F25 | 作業連携 | CLIとGUIで同じ入力・設定を処理する | 同じ契約と結果の意味、終了コード、再実行 |
| F26 | 対面表示 | 参加者の言語、向き、文字サイズを変更する | 各閲覧者の設定に合う字幕、共通原文との対応 |
| F27 | 交互通訳 | 発話・確認・読み上げ・割込みを組み合わせる | 発話区間、音声経路、停止の応答 |
| F28 | 話者の照合・訂正 | 登録・未登録・短い声・言語切替・訂正を扱う | 同意、誤割当と判定割合、未割当と手動修正 |
| F29 | 複数参加者の翻訳 | 参加者数・訳先数・表示領域を変更する | 資源に応じた配置、同一条件の結果共有 |
| F30 | 会議・インタビュー | 話者交代・重複・保存選択・後処理を扱う | 時間・話者・訂正履歴、保存方針との一致 |
| F31 | 音声経路の選択 | 入力・出力機器の切替、切断、OS割込みを行う | 経路の状態、取得と出力の復帰、字幕継続 |
| F32 | モデル管理 | モデルの許諾・取込み・検査・切替・削除を行う | 資産の同一性、演算と資源、同意、参照の解放 |
| F33 | 能力と多言語設定 | 導入状態・能力・言語経路・UI言語を変更する | 処理別の能力表示と実行判定の一致 |
| F34 | 資源制御 | メモリ・熱・電源・負荷・優先順位を変更する | 共通予算、待ち量、選択した品質方針、再開 |
| F35 | データと権限 | 保存・取得・通信・権限・同意を変更する | 目的と範囲、保持期間、データ経路の実測 |
| F36 | アクセシビリティ | 表示倍率、方向、入力手段、読み上げを切り替える | 全主要画面の操作、フォーカス、通知、識別性 |
| F37 | 診断と復旧 | 障害を注入し状態説明・復旧操作・ローカル診断を確認し、利用者が選んだ診断情報を確認後に出力する。鍵不在・保護ストア拒否・破損・誤回復情報・初期化または復元の中断も扱う | 再開手段、確認した診断内容と保持方針、分類された失敗、既存データ保持、秘密情報を含まない選択出力と復旧経路 |
| F38 | 配布と互換性 | 配布成果物・契約・保存変換を照合する | 依存と通知、署名、回復手段、能力とデータの整合 |

## 横断する受入項目

| 項目 | 適用する確認 |
|---|---|
| 多言語 | 方向ごとの能力、混在言語、Unicode、書字方向、文字体系、UI資産 |
| 保存 | 一時利用・永続化・保持期限、原資料・生成結果・編集の由来 |
| 実行 | 入力の同一性、部分と確定、取消、再開、終端、資源の解放 |
| 権限 | 対象と目的、取得中の表示、許可変更、同意と撤回 |
| 利用条件 | 導入物ごとの条件、配布依存の採用根拠、通知 |
| 資源 | メモリ、計算、温度、電力、I/O、待ち量、操作応答 |
| セキュリティ | 解析上限、所有権、隔離、入力変異、署名と由来、保存失敗時の平文フォールバック禁止、秘密情報を含まない診断 |
| OS統合 | ライフサイクル、ファイル、入力メソッド、画面・音声、アクセシビリティ |
| モバイルのタスク切替 | Android/iOSで原文・訳文を入力し、タスク切替・復帰・前景撮影を行う | プレビューに原文・訳文がないこと、原文・訳文・フォーカスの復帰、前景撮影が可能であること、OS版と機種 |
| 配布 | モデル資産の別導入、実行時ロード、推移的依存、通知、能力表 |

## 記録する項目

各試験は機能ID、必要能力、言語・形式・資源の条件、入力の内容識別、使用するモデル資産、操作、観測値、受入閾値、結果、確認者を持つ。閾値は用途別の評価設計で定め、結果には測定条件を添える。

試験実施は設計資料の構造検査、処理実装の契約試験、各環境の統合試験、品質・性能試験、配布物の監査に分けて記録する。
